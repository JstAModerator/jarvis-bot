Jarvis Bot Privacy Policy

Effective Date: August 30, 2026

1. Overview

Jarvis Bot values your privacy. This policy explains what data we collect, how we use it, and your rights regarding that data.

2. Data We Collect

Jarvis only stores minimal data necessary for command functionality — such as server IDs, user IDs for reminders, and configuration settings. We do not collect or store message content.

3. How We Use Data

Data is used solely to provide bot features like reminders, settings, and uptime tracking. We never sell, share, or monetize user data.

4. Data Security

All stored data is protected using secure database practices. Access is limited to authorized systems required for Jarvis’s operation.

5. User Rights

You can request deletion of stored data by removing Jarvis from your server or contacting the developer directly.

6. Changes to This Policy

We may update this Privacy Policy periodically. Continued use of Jarvis after updates means you accept the new version.

7. Contact

For questions or concerns, reach out to Saady via Discord or email at jarvisbot.support@example.com.
